### 🧑‍🎨 Head Lab

<a href="https://modrinth.com/mod/head-lab"><img src="assets/headlab.gif" width="100%" alt="Head Lab: a player head being painted texel by texel on the editor's net while the finished head turns in 3D, beside a Minecraft tooltip with its downloads on Modrinth and CurseForge"></a>

An in-game custom player head editor for Fabric. Press <kbd>K</kbd>, paint all six faces on a pixel net, watch the live 3D preview, and the head lands in your inventory, on any server, with no OP, plugins or commands.

Get it on **[Modrinth](https://modrinth.com/mod/head-lab)** or **[CurseForge](https://www.curseforge.com/minecraft/mc-mods/head-lab)**.

[![modrinth](https://img.shields.io/modrinth/dt/head-lab?logo=modrinth&label=modrinth&color=1bd96a&labelColor=13131c&style=flat-square)](https://modrinth.com/mod/head-lab)

### 🦀 claude-fleet

<a href="https://github.com/Sowiastyy/claude-fleet"><img src="assets/claude-fleet.gif" width="100%" alt="claude-fleet: a session list on the left, a Claude Code session fixing a test on the right, and Clawd dancing in the corner"></a>

A terminal multiplexer for Claude Code sessions, written in Rust: the session list on the left, the full interactive terminal of the selected session on the right, and Clawd dancing in the corner. Windows and macOS.
